# DATEMENU for Tomimimi

## Фото
Положи jpg в `public/photos/`: `hero.jpg`, `picanha.jpg`, `ribeye.jpg`, `chuck-eye.jpg`, `top-blade.jpg`, `new-york.jpg`, `tri-tip.jpg`. Пока файла нет, показывается заглушка.

## Telegram
Секреты репозитория: `TG_BOT_TOKEN` и `TG_CHAT_ID` (Settings > Secrets and variables > Actions). Для локальной работы скопируй `.env.example` в `.env.local`.

## Запуск
`npm install && npm run dev`
